Atlas-X Cursor Studio v1.0.1，适用于 Windows 10 / 11 64 位。

## 下载与更新

1. 在托盘图标菜单中退出正在运行的旧版。
2. 下载 `AtlasXCursorStudio-Setup-1.0.1.exe` 并运行，可覆盖安装旧版；保留用户配置和自定义光标。
3. 不需要安装时，下载 `AtlasXCursorStudio-portable-1.0.1.zip`，完整解压后运行其中的 `AtlasXCursorStudio.exe`。请保留同目录的 `_internal` 文件夹。
4. `Source code (zip/tar.gz)` 是源码，不是可直接运行的安装包。`SHA256SUMS.txt` 可用于检查下载完整性。

## 改进

- 配置损坏自动备份并回退，使用原子保存保护原配置。
- 自动抠图改为后台执行，界面保持响应，失败后可重试，退出时等待任务结束。
- 新快捷键注册失败时保留旧快捷键和原设置。
- 生成的光标缓存存入用户目录，减少重复渲染。
- 修正图片方向、透明度和预览与实际光标不一致的问题。
- 模型下载增加超时、临时文件校验和原子替换。

## 验证与说明

发布流程先执行自动测试，再检查打包程序的资源、配置读写、主窗口、光标生成和 ONNX 运行库导入，通过后才发布下载文件。

首次自动抠图仍可能下载第三方 U2Net 模型。真实多屏、全屏和不同 DPI 场景需要进一步实机验证。第三方说明及许可文件随程序一同打包。
