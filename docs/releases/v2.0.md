Atlas-X Cursor Studio v2.0 适用于 Windows 10 和 Windows 11（64 位）。

### 更新内容

- 动态主题使用 Windows 原生 ANI 播放。应用在主题、尺寸、配色或动画速度变化时更新系统光标。全屏暂停时切换至静态光标，退出全屏后恢复。Windows 无法加载动画时会回退至静态主题，工作台显示当前状态。
- 工作台提供聚焦准星、声呐波环和静态标记三种定位样式。点击画布可试用左、中、右键的波纹，按空格可预览定位效果，也可在桌面直接试放。定位效果沿用尾迹颜色。
- 新增棱镜 Prism 和轨道 Orbit，共 12 套内置主题。主题列表显示缩略图，试选、配色和应用仍可分步完成。
- 点击和晃动共用一次位置采样，横向和纵向晃动都可触发尾迹。覆盖层按效果范围重绘，跨屏轨迹按显示器裁切，全屏暂停会清除尚在播放的效果。
- 再次打开程序会唤出原有窗口。系统托盘和全局快捷键由同一个实例管理。

### 安装与升级

从系统托盘退出旧版，下载并运行 `AtlasXCursorStudio-Setup-2.0.exe` 即可升级。便携版用户请完整解压 `AtlasXCursorStudio-portable-2.0.zip`，保留同目录的 `_internal` 文件夹，然后运行 `AtlasXCursorStudio.exe`。原有主题、快捷键和自定义光标会从原用户目录读取。可使用 `SHA256SUMS.txt` 核对下载文件。
